# ISAT 340 Flask Mini-Project

## Overview

This project demonstrates a functional Flask web application with user login, profile management, and the ability to view celebrity information stored in a SQLite database. It highlights core skills in backend development, HTML templating, database operations, and CSS styling.

---

## Project Objectives
<img src="https://github.com/user-attachments/assets/55ab571f-eb34-44d2-bf28-3b63bb90fdfc" width="250" align="right">

* Build a working Flask application.    
* Create and modify a SQLite database.
* Develop HTML pages for login, profile editing, and data display.
* Use forms to update and store profile information.
* Display database records aesthetically.
* Apply external CSS styles.
* Load and display remote celebrity photos.
* Allow users to view one celebrity or all celebrities.
* Deploy application on AWS Server

## Running the Application
<img width="157" height="131" alt="image" src="https://github.com/user-attachments/assets/69550dbb-05eb-4781-827e-6ba8cef91089" align="right" />

1. Install Python and SQLite.
2. Run the Flask file:
   FlaskAppProject_LastName.py

3. Open the terminal and Ctrl+LeftClick on
the http://localhost:5000 link to open the program
   
4. Log in with memberID, username, and password from the database.

## How to Use
<img width="1091" height="195" alt="image" src="https://github.com/user-attachments/assets/759f67c4-e5a6-4ad8-88c3-66937c879e25" align="right" />
* Type in your browser: http://ec2-98-93-2-167.compute-1.amazonaws.com:5000/
* Enter memberID, username, and password on the login page.
* View or update your profile information.
* Navigate to:

  * View All Celebrities
  * View One Celebrity
* Any changes submitted are stored back into the SQLite database.
